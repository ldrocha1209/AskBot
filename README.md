# AskBot

Welcome to AskBot!

This program was created to be able to search topics, people, and definitions on Wikipedia using your terminal.

To use this program, open your terminal use CD to navigate to the directory (folder) that the file 'chatbot.py' is located. Once you have located where it is, to run and use it simply type in your terminal:

python3 chatbot.py

Or (depending on what version of python you have)

python chatbot.py

Once the program is running, follow the instructions on screen to navigate the program and find the information you need. You can ask the program questions formatted like:

- Who is...
- What is...
- Define...
- Tell me about...

When you are done you can either type 'exit', 'bye', or 'quit' to close the program. Enjoy!
